# RotaLantern

A free, printable four-week chore rota for shared homes. Add people and chores, then print the plan or download a CSV file.

The page runs in the browser. Entered names and chores are never submitted to a server. No account is needed. The site counts visits and print or download actions without sending rota entries.

Visit [RotaLantern](https://zaimimr.github.io/RotaLantern/).
